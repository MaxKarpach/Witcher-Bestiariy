# Бестиарий — The Witcher TTRPG

Интерактивный бестиарий для системы The Witcher TTRPG: создание существ, параметры и броски атака/защита.

## Стек

- React 18, Functional Components, Hooks
- TypeScript
- CSS Modules
- Vite
- Без backend и сторонних UI-библиотек

## Запуск

```bash
npm install
npm start
```

Откройте в браузере адрес, который выведет Vite (обычно `http://localhost:5173`).

Сборка продакшена:

```bash
npm run build
npm run preview
```

## Структура проекта

- `src/types` — типы (Creature, RollRecord, RollSide и др.)
- `src/utils` — расчёт броска, парсинг, id
- `src/context` — CreaturesContext, RollHistoryContext, ModalContext
- `src/components` — Modal, SideSelectionModal, ValueInputModal, ParameterValue, CreatureCard, RollHistory
- `src/App.tsx` — провайдеры и разметка приложения

## Логика

1. **Существа** — кнопка «Новое существо», inline-редактирование имени, описания, URL изображения и параметров по группам:
   - **Основные**: Инт, Реа, Лвк, Тел, Скор, Эмп, Рем, Воля
   - **Дополнительные**: Уст, Бег, Прж, Вын, Вес, Отдых, ПЗ
   - **Основы навыков**: названия задаёт пользователь (добавление/удаление)
   - **Защита**: Уклонение, Блокирование, Смена позиции
2. **Параметр** — число кликабельно: открывается модалка «Какая вы сторона?» (Атака / Защита), затем модалка с полями Атака и Защита и кнопкой «Ввод». Выбранный параметр отображается как модификатор (например, 12+) у соответствующего поля.
3. **Бросок** — по «Ввод» считается разница (атака − защита), в историю добавляется запись с пошаговым расчётом и результатом «Попадание» или «Промах».
4. **История** — компонент `RollHistory` только отображает переданный массив записей; расчёты в `utils/rollUtils.ts`.

Модальные окна закрываются по клику вне окна и по ESC, фокус удерживается внутри модалки.
